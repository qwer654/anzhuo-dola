# 功能矩阵与验收边界

来源：桌面发布包的 `DolaMultiBrowser.deps.json`（版本 2.3.1）、现有旧版 1.4.8 源码与当前 `Extensions/dola30`（MV3 1.6.11）。新版 `v231` 只有部分现有类，因此不能把未知部分当作已完成。下列“已实现”仅指源码实现，不代表全部真机验收通过。

| 能力 | Android 0.1 | 说明 |
|---|---|---|
| 豆包/Dola/即梦/千问/云雀入口 | 已实现 | 可编辑 HTTPS 首页；第三方网站可能拒绝 WebView 登录 |
| 8 个独立账号空间 | 已实现 | 每个空间是独立 Android 进程和 Chromium 数据目录；未读取或导入桌面 Cookie |
| 浏览、前进/后退、刷新、上传 | 已实现 | 网页文件选择走系统文档选择器；不允许 file:// 访问 |
| 白名单页面媒体观察 | 已实现（安全子集） | 只观察页面已有 JSON/fetch/XHR/DOM/Performance 里的图片/视频 URL；不请求 fallback_api、不修改响应 |
| 资源下载 | 已实现 | 用户逐项点击，交给 Android DownloadManager；仅 HTTPS |
| 30 秒/时间码 | 部分 | 本地提示词比例工具；不伪造模型能力，不保证平台接受 30 秒 |
| 快捷文本 | 已实现 | 本地 CRUD、复制或填入当前网页；不会自动发送 |
| 分镜工作台 | 已实现（手动） | UTF-8 文本按空行导入、编辑、三态手动状态、JSON 备份；不代表平台生成状态 |
| Cookie 导入/导出 | 未实现 | 必须显式设计安全迁移与用户确认 |
| 多标签、书签 | 未实现 | 当前每个账号空间是单页 WebView |
| CDP 深度嗅探/Fetch.fulfillRequest | 未实现 | Android WebView 没有桌面 WebView2 等价能力 |
| HTTP/SOCKS5 认证、链式代理 | 未实现 | 需要重新设计 Android 网络层 |
| UA/时区/Canvas/Audio/WebRTC 指纹 | 未实现 | 不用伪造或绕过平台安全 |
| 批量自动生成、发送、后台任务 | 未实现 | 目前只提供用户确认后的网页填入 |
| 遮罩、人脸、参考音频、创作中心、百宝箱 | 未实现 | v231 仅有入口线索，组件源码不完整 |
| Windows 机器码、注册表、WPF API | 不适用 | Android 无对应运行时 |
| 本地自动化 API 17823 | 未实现 | 原桌面接口仅回环绑定，未暴露到手机网络 |

## 最低验收

1. GitHub Actions `assembleDebug` 成功并上传 APK。
2. Android 9+ 真机可以创建两个空间，登录状态互不共享。
3. 网页上传、工作台填入、资源观察、用户点击下载各自可用。
4. 网络断开或网页改版时显示失败，不把失败伪装成生成成功。
